Embedding map

Every chunk is a point in a space with hundreds of dimensions. This flattens that space onto the two directions along which your chunks differ most, so related chunks land near each other. Add a question to see where it lands and which chunks are truly nearest to it.

Entity graph

With chunking.entity_graph on, ingestion records which named things (registers, error codes, functions) each chunk mentions and how they relate. This is what entity-graph retrieval looks things up in: an entity named in a question brings in the chunks that mention it and the chunks of the entities one step away.

Presets
A preset of your own

Like the built-in presets, yours starts from the dense baseline, not from your saved configuration. Set what you want to measure, give it a name and add it.

    Retrieval only never calls the chat model. Retrieval with LLM help lets it take part in retrieval (HyDE, multi-query, decomposition, multi-hop, the LLM reranker) without writing answers. Answers add keyword, refusal and citation checks; keyword coverage does not prove grounding. Document-level scores cannot measure wider neighboring context.

    The judge is a language model reading each answer: its scores are noisy on small models and flattering when a model grades itself. Compare averages and spot-check rows by hand.

    Manual answer review rubric
    1. Can each factual claim be supported by an inspected passage?
    2. Do the cited sources actually support the claim, rather than merely sharing its topic?
    3. Does an answer acknowledge missing or contradictory evidence?
    4. Did any retrieval gain justify the measured latency and longer prompt?

    One row per stage of the learning path (docs/00_LEARNING_PATH.md). Open a stage to tick the things you can now do. Your progress is kept on this computer and is the same in the desktop app and on the command line.

    Quiz

    The questions and reference answers are the interview Q&A (docs/02_INTERVIEW_QA.md). Write your answer before you look: the chat model then lists the key points you covered and the ones you missed, or you compare with the reference yourself. Questions you got wrong come back first.

    Guided labs

    Small experiments with this app, one idea each. Opening a lab takes you to the right panel with the question and settings filled in; you press the button there. Each lab says what to look for. They are written for the sample corpus in documents/.
